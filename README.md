# 📚 Gestionnaire de Bibliothèque Personnel

API REST développée avec Spring Boot pour gérer une collection de livres personnels (titre, auteur, ISBN, date de lecture, note).

## 🚀 Technologies utilisées

* **Java 21** (utilisation des *Records* pour les DTOs)
* **Spring Boot 3** (Spring Data JPA, Spring Web, Bean Validation)
* **Base de données H2** (en mémoire)
* **JUnit 5 & Mockito** (tests unitaires)
* **Maven** (gestionnaire de dépendances)

## 🛠️ Préréquis

* Java 21 installé
* Maven (ou le wrapper `./mvnw` inclus)
